**프로젝트 소개**

이 프로젝트는 테니스 경기 기록과 관리를 위한 콘솔 기반 애플리케이션으로, 선수 정보 등록 및 조회, 경기 진행, 실시간 점수 계산, 경기 결과 저장 등의 기능을 제공합니다. 플레이어의 성별과 이름을 검증해 경기 규칙을 적용하며, 최종 결과를 파일에 저장해 관리할 수 있습니다. Java와 파일 입출력을 활용해 데이터 처리 및 사용자 친화적인 인터페이스를 구현하였습니다.


**목표**

1. 테니스 경기 점수 및 결과를 실시간으로 기록하고 저장하는 시스템 구현
2. DAO를 활용해 데이터의 저장, 조회, 수정, 삭제 기능 구현
3. DTO를 통해 선수 및 경기 데이터를 객체 단위로 전달하고 관리
4. 경기 점수 계수기를 통해 자동으로 점수를 계산하고 처리


**핵심 기능**

1. 새로운 경기 시작 시 성별 및 이름 검증을 통한 경기 조건 설정
2. 경기 점수를 자동으로 계산하고 세트별, 게임별 결과를 기록
3. 선수 등록 및 중복 검사, 유효성 검사를 통한 데이터 관리
4. 지난 경기 기록 불러오기 및 상세 결과 확인 기능


**주요 사용 기술**

Java, 파일 입출력 (I/O), 객체 지향 프로그래밍 (OOP), Scanner, Calendar, Random, JFiglet


**성과**

1. 경기 점수 자동 계수를 통해 테니스 경기 기록 관리의 효율성 향상
2. 선수 정보 등록 및 검증 기능으로 데이터의 신뢰성 강화
3. 파일 입출력을 활용한 경기 결과 저장으로 데이터 영속성 확보
4. 세트 및 게임 단위 경기 결과 제공으로 사용자 편의성 증대
5. 직접 입력 기반 계수기 리팩토링으로 사용자 선택의 유연성 강화
